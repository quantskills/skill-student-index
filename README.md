# 大学生指数 (Student Index)

> 基于擦鞋童理论的 A 股散户情绪反向指标 Agent Skill。

## 这是什么

分析东方财富股吧 + 全网平台（小红书 / 微博 / 雪球 / 贴吧）上学生党、大学生的投资讨论，
通过 7 维关键词规则识别「学生党帖」，计算情绪指数并生成自包含 HTML 可视化看板。

**核心假设**：当年轻、本金少、风险偏好高、易跟风的群体大量涌入某类资产时，
该资产往往已过热 —— 这是反向卖出信号。

## 指数构成

```
大学生指数 = 学生党占比 × 40% + 学生党强度 × 25%
           + 情绪极端度 × 20% + 信号纯度 × 15%
```

| 区间 | 解读 |
|------|------|
| > 65 | 过热，反向卖出信号 |
| 35–65 | 正常波动 |
| < 35 | 恐慌，可能见底 |

覆盖：纳斯达克ETF(513100)、黄金ETF(518880)、CPO通信ETF(515880)、半导体ETF(512480)

## 快速开始

```bash
python main.py
```

无联网时自动回退到内置示例数据，仍可完整跑通并产出看板。

接入 Agent 联网搜索能力：

```python
from main import run_student_index

def my_search(query: str) -> list[dict]:
    ...

result = run_student_index(search_web_func=my_search)
```

## 目录结构

```
SKILL.md                     技能定义（Agent 直接读取）
main.py                      主入口：采集 → 分析 → 计算 → 生成看板
scripts/
  guba_collector.py          股吧采集（标准库 urllib，零第三方依赖）
  web_searcher.py            多平台关键词生成与结果归一化
  analyzer.py                7 维度关键词分析引擎
  index_calculator.py        指数计算 + 建议生成
  template.html              自包含看板模板
使用说明_大学生指数.md
```

## 设计取舍

- **零专属平台依赖**：不使用扣子 / Coze 等任何平台接口，只用 Python 标准库发起请求，
  任何具备联网能力的 Agent 都能直接跑。
- **可离线验证**：网络不可用时不报错，回退示例数据保证流程完整可演示。
- **规则可审计**：识别与打分全部基于显式关键词规则，不依赖黑盒模型，结论可逐条回溯。
